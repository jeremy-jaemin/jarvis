# jarvis

개인 유틸리티 모음. 반복되는 잡일이나, 손으로 하기엔 타이밍이 빡센 일을 대신 처리하는 도구들을 모아둔다.

대부분 한 번 쓰고 버리기 아까운 것들이다. **도구 자체보다, 만들면서 알아낸 것들을 남기는 데 무게를 둔다.**
남의 서비스를 자동화하다 보면 문서에 없는 함정을 계속 밟게 되는데, 그걸 기록해두지 않으면 다음에 또 밟는다.

## 유틸리티

| 디렉터리 | 설명 |
|---|---|
| [`cgv-auto-booking`](cgv-auto-booking/) | CGV 매진 회차에서 취소표가 나오면 좌석을 잡고 결제 직전까지 진행 |

## 구성 규칙

- 유틸 하나당 디렉터리 하나. 서로 의존하지 않게 자립적으로 만든다.
- 각 디렉터리에 `README.md`(사용법)를 둔다.
- 리버스 엔지니어링이 필요했던 것은 `docs/FINDINGS.md`에 **실측값과 함께** 따로 남긴다.
  "이렇게 하면 된다"가 아니라 "이렇게 하면 안 되고 왜 안 되는지"를 적는다.
- 자격증명·토큰·계정 식별자는 커밋하지 않는다. 설정은 `config.example.json`으로 두고
  실제 `config.json`은 `.gitignore`에 넣는다.

## 자동화에 대한 원칙

- **되돌릴 수 없는 동작은 자동화하지 않는다.** 결제·삭제·전송 같은 것은 직전에서 멈추고 사람에게 넘긴다.
- 폴링 주기는 상대 서버가 감당할 만한 선에서 잡는다. 응답 크기와 소요 시간을 먼저 재보고 정한다.
- 실패했을 때 **왜 실패했는지 로그로 남게** 만든다. 조용히 실패하는 자동화가 제일 나쁘다.

## 브라우저 자동화

브라우저를 다루는 유틸은 [cmux](https://cmux.app) CLI로 실제 브라우저 세션을 조작한다.
로그인 세션을 그대로 쓰므로 별도 인증 처리가 필요 없고, 헤드리스 탐지에도 걸리지 않는다.

```bash
cmux browser --surface surface:N get-url            # 서피스 찾기
cmux browser --surface surface:N eval --script '…'  # 스크립트 실행
cmux browser --surface surface:N screenshot --out x.png
```
